# FlixNest

FlixNest is a greenfield **Tauri 2 + React + TypeScript** media application shell designed for:

- desktop PCs via Tauri
- Android/mobile via Tauri mobile tooling
- TV-style experiences through a dedicated 10-foot responsive mode

The project currently focuses on a **legal-first media center architecture** for personal libraries, public-domain catalogs and otherwise authorized sources.

## Included foundations

- modern responsive app shell for desktop, mobile and TV navigation
- discover view with hero section, shelves and continue-watching cards
- player surface with:
  - selectable playback profiles (`Auto`, `Exo Profile`, `MPV Profile`)
  - decoding and renderer presets
  - intro skip action
  - picture-in-picture trigger
  - hold-to-boost playback interaction
  - subtitle overlay sizing
  - aspect ratio controls
  - external player launch
- provider management with enable/disable, rename, endpoint editing and ordering
- sync dashboard for Trakt, MyAnimeList and Kitsu account wiring state
- multi-profile management
- offline/download queue surface
- persistent local state via browser/Tauri storage

## Commands

```bash
npm install
npm run dev
npm run build
npm run tauri dev
npm run tauri android init
```

## Notes

- The UI uses only the dependencies generated by the official Tauri scaffold.
- The current implementation is intentionally legal-first and does **not** include torrent streaming, copyright-infringing source integrations, or ISP-block-evasion behavior.
- Android/APK generation depends on the host Android SDK/NDK setup.
